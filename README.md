# Letter Game · اسم حيوان نبات

## ▶ [Play the game](https://libyan11.github.io/letter-game/)

https://libyan11.github.io/letter-game/

The classic letter game (اسم، حيوان، نبات، جماد، بلاد) on your phones, in Arabic or English. Part of [Game Night](https://libyan11.github.io/).

**How to play**
- A letter comes up. Fill every category with a word that starts with it.
- Filled everything? Shout **STOP!** and everyone else gets 5 seconds.
- Everyone checks the answers together. Tap ✗ on one that doesn't count; if more than half of the others agree, it scores nothing.
- 10 points for a good answer nobody else had, 5 if someone else wrote the same.

**Play with friends:** one person taps *Create a room* and shares the 4-letter code or link. The host picks the language, the categories (3 to 8), how many letters and how long each one lasts.
